DM99 PRO GUIDE 📖

BASICS

  • Select an instrument by clicking its name
  • Click on the pads to activate/deactivate steps
  • For Bass/Synth, adjust pitch with the knobs
  • Use 🔇 to mute and 🔊 to solo instruments
  • Adjust volume with the sliders

PATTERNS

  • Save your patterns with 💾 SAVE
  • Load patterns with 📂 LOAD
  • Delete patterns with 🗑️ DELETE
  • Clear current pattern with 🧹 CLEAR

CONTROLS

  • Adjust TEMPO (60-200 BPM)
  • Add SWING (0-100%)
  • Set NOTE PROBABILITY for random skipping
  • Use FILTERS to shape your sound
  • Adjust EQ for master and bass/synth
  • Select different SCALES for melodic parts

ADVANCED

  • Use ADSR to shape instrument envelopes
  • Generate random patterns with 🎲 buttons
  • Click ▶️ PLAY to start and ⏹️ STOP to halt
  • Adjust master volume with 🔊 at top right
